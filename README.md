# k8s-orch-pipeline

A Cloud-ops pipeline to automate ML model deployment on a openstack server and maintain the same.

## Features
- All steps required to deploy the model are automated
- Supports Openstack
- Bash/Python scripts to help automation
- Terraform to control the kubernetes cluster and upscale/downscale at demand


> Note:
> This is a demo for a large scale project and thus, open to changes at anytime.
